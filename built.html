CircuitGuard

A real-time safety system for Formula 1 that cuts the delay in race-control decisions. Winner of the Ampere "AI for Motor Safety" prize at FormulaTech Hacks 2026, built with a team of four.

What it does

  • Reads live driver telemetry to spot crashes and stopped cars at or near the racing line
  • Judges severity and suggests the right call (safety car, VSC, red flag) from the 2026 FIA sporting regulations
  • Alerts following drivers almost immediately
  • Scores spectator and driver risk per track section to support fairer, section-based insurance premiums

How it's built

  • Python/FastAPI backend on the OpenF1 API, with NumPy and Pandas
  • Bayesian Monte Carlo insurance-pricing model and a real-time telemetry anomaly detector
  • sentence-transformers + FAISS semantic search over the FIA regulations; faster-whisper for radio transcription
  • Next.js/React frontend with react-three-fiber for a 3D track view

MUN Chair Toolkit

A local-first committee-management app for Model UN chairs and vice-chairs, replacing paper roll calls and hand-counted votes.

What it does

  • Committee and agenda setup
  • Single or bulk delegation entry (one country per line)
  • Roll call with Present, Present and Voting, and Absent
  • Automatic quorum, simple-majority and two-thirds calculations

How it's built

  • Rules kept in framework-free functions (src/lib/rules.ts) with automated tests, separate from the UI
  • GitHub Actions workflow runs checks
  • All data stored in-browser with IndexedDB, so it works offline with no account or backend
